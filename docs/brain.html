The signal path

A request enters at the left. It cannot reach “done” without passing a check that is allowed to say no.

Four faculties

Each answers one question, and each is checked by something that can fail.

Routing

which agents, at what cost

Deterministic rules first, a weighted score only when nothing matches. No model is involved, so the whole probe set runs in seconds and can gate every commit.

24 active 11 validation 6 passive 5 control

Model tiers: 13 opus · 31 sonnet · 2 haiku. The control plane exists to prevent dispatches — an agent that cannot pay for its own latency is theatre with better vocabulary.

Protocol

what an agent must return

Twelve fields, in two tiers. Five are required; seven must be addressed — and the rule that makes those enforceable is that silence is not an option.

status · summary · voice · log · handoff
objective · findings · testing · files_changed · dependencies · risks · questions

An omitted risks and a risks: none read identically to whoever picks the work up, and only one of them is a statement. Seven of these twelve used to be declared in the registry and rendered to nobody.

The loop

is it good yet

Three rounds, a panel, and four halt conditions with code behind every one. Revisions go back to the original author with the objection verbatim — the author holds the context, and a paraphrase loses the thing objected to.

Disagreement is a procedure, not a ranking: 5 steps, a 6-deep tiebreak where safety outranks architecture on purpose, and 3 conditions that go straight to a person.

Memory

what it knows about the ground

A deterministic context pack, scoped per role so a UI agent is not handed the DocType inventory. Plus an optional code graph — 1,608 nodes and 1,887 edges of real call, import and inheritance structure.

18 write scopes keep two agents from editing the same area at once, and the outcome ledger records what every dispatch actually produced.

The refusal cycle

“Done” is a computed verdict. Ambiguity always resolves toward another round, because the two mistakes cost wildly different amounts.

What it actually refuses

Real output from the real command. Each of these was previously indistinguishable from a finished task.

The graph layer

Impact analysis used to mean grep. A file listing says what exists; it cannot say what calls what.

An optional Graphify graph is read if one is present — a JSON file another tool produced, so there is no dependency, no subprocess, no network and no model call. Absent, everything degrades to exactly the previous behaviour.

FreshnessMeaningWhat it does
fresh Built at HEAD.Answers normally.
current by content The commit moved on; none of the graphed source files did. Treated as usable. A warning that fires when nothing is wrong is one people learn to scroll past.
stale Graphed sources changed — and it names how many. Loud. A stale graph is worse than none: it answers confidently, about code that has moved, and nothing in the answer looks wrong.
unknown No recorded commit, or not a repository. Treated as possibly stale. “Cannot check” and “checked and fine” must never render the same.
Found on the first real run

An existing graph on this machine was 43 commits behind, with 57 of its own source files changed. It would have produced confident, wrong impact analysis, and nothing in the output would have said so.

What is not true yet

A page that lists only wins is the failure mode this system was built to detect.

The ledger is empty

Zero rows. Every agent-health metric is therefore computed over an empty set, and learn has never run on real data. The machinery is built and tested; the loop is unproven. doctor now says so out loud, because “the loop is built” and “the loop is working” are different claims and only one of them was ever checkable.

LimitWhy it stands
The driver does not dispatch It answers “is this done?” and names who is next. It removes the ability to skip the question, not the ability to ignore the answer.
It cannot judge quality It checks protocol compliance, declared gates, and whether evidence looks like output. Whether a reviewer was right stays the panel's job.
Objection matching misses derivations Inflections unify — “orphan”, “orphaned”, “orphaning” are one objection. “Submit” and “submission” do not. Fixing that needs a dictionary, which is a dependency.
Write scopes are directories Not per-file. Two agents writing different files in one directory are serialised unnecessarily — conservative in the safe direction, but a real cost.
